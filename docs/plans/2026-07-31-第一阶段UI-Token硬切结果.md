## 4. 后续 Review 建议顺序

结合命中规模和页面基础程度，建议依次处理：

1. App Shell、侧栏和全局导航；
2. 会话布局、Tabs 和历史列表；
3. Workspace、Task Panel 和交付物；
4. 消息、Markdown 和工具调用；
5. 设置、渠道、团队和 Cron；
6. Skills 和 Agents；
7. Preview、编辑器、终端、图表和 Webview；
8. Avatar 等独立 Renderer。

每个区域同时完成 Token 迁移、硬编码颜色审查、重复 CSS 删除和明暗模式检查，不做全局机械替换。
