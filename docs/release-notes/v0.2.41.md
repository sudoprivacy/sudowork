# Sudowork v0.2.41 Release Note

> 发布源以正常合并后的固定提交为准；包含已审核的浏览器、共享编译器及运行环境升级修复。实际候选包、配套服务能力与线上验收分别留证。

## 重要修复

- 修复 Windows 升级运行环境时，已退出桌面程序留下的空闲 scode 服务占用 `scode.exe`，导致新版工作台无法启动的问题。替换前由旧引擎正常关闭服务，并等待其进程及可执行文件句柄释放。
- 存在活动 Agent 或需要协调退出的共享 Box 时，安装会停止，并保留原运行文件及版本记录，供用户结束当前工作后重试。

## 浏览器交互

- 浏览器页面拖动经过桌面与 WebUI 共用的查看器输入队列；消费者固定使用已发布的浏览器运行环境。

## 工程调整

- 本体编译器执行逻辑由各宿主共用；原生 Node 构建先构建其共享依赖。

## 验证与发布边界

- 升级修复已有 22 项安装及协议检查，升级修复源码 `549a460f` 全量 3,611 项通过；本版本集成全量结果另存发布验收记录，29 项条件跳过。原始失败及环境准备记录保留，没有修改断言或期限。
- 原 0.2.38 → 正式 0.2.40 的更新、原会话上下文、文件工具及 owner 计费已经实际核对，但该轮需要手动正常关闭旧服务。它不是新版自动修复的验收证据。
- 本版本还需通过全量 CI、正常合并队列、官方候选构建及原安装升级验收。版本、源码和资产均按实际结果留证。
