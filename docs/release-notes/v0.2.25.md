# Sudowork v0.2.25 Release Note

> 紧急桌面端回退版本。桌面产品行为恢复至 v0.2.20（`967a05c9`）基线；发布版本提升至 v0.2.25，使已安装 v0.2.24 的客户端能够通过正常自动更新回退。

## 回退范围

### 桌面端

- 恢复 v0.2.20 的桌面端代码与充值中心稳定性行为。
- 桌面端安装包与更新元数据版本统一为 v0.2.25。
- 保持 macOS arm64、macOS x64 与 Windows x64 的桌面发布矩阵。

### 不包含

- 不构建、不上传或更新 WebUI Docker 包。
- 不更新 WebUI 安装脚本、WebUI 配置或 WebUI COS 发布路径。
- 不回退服务端配置、数据或 API。

## 发布投递保护

- macOS updater metadata 的顶层 `path` 与 `sha512` 规范化为对应架构的 ZIP，避免 electron-updater 选择 DMG 作为自动更新资产。
- 若 macOS 构建因 notarization 或 stapling 错误退出，只有对应 DMG、ZIP 与 ZIP blockmap 均已生成时才允许发布流程继续。
- 更新 mock release artifact fixture，覆盖 x64 macOS metadata 初始指向 DMG 后被规范化为 ZIP 的场景。

## 本地验证

- `bun install --frozen-lockfile` 通过。
- 共享 packages 构建与桌面端 TypeScript 检查通过。
- mock artifacts 经 `prepare-release-assets.sh` 与 `verify-release-assets.sh --all` 验证通过；`latest-mac.yml` 和 `arm64-mac.yml` 均指向对应架构 ZIP。
- 完整 `bun run check` 在 lint 阶段被 v0.2.20 基线中既有的 96 个规则/格式错误阻断，本次改动文件不在错误列表中。

## 发布前待验证

- 在 CI 完成桌面端 macOS arm64、macOS x64、Windows x64 构建。
- 验证代表性 v0.2.24 用户配置可覆盖更新至 v0.2.25，并完成登录、充值与本地数据保留检查。
- 发布前后比对 WebUI `latest/install.sh` 摘要，确认没有变化。
