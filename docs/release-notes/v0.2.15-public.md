## v0.2.15

### 新功能

- 新增本地知识库管理能力，可在桌面端管理本地知识库与相关运行时依赖。
- 支持安装本地知识库所需的向量模型运行时。
- 支持安装本地文档解析所需的 Poppler 运行时。
- 支持配置 scode 自动模型，让自动模型选择更灵活。

### 修复

- 修复本地知识库部分运行时依赖缺失导致功能无法启动的问题。
- 优化本地知识库运行时安装与验证流程，提升 Windows 和跨平台环境下的成功率。
- 修复团队会话中可能出现的重复消息、无意义补充消息和成员等待状态异常。
- 修复团队面板中成员产物展示不完整的问题。
- 修复登录态恢复后凭据未及时生效的问题。
- 更新自动模型路由配置，确保使用最新模型选择规则。

### 性能

- 本版本主要聚焦功能与稳定性修复，无单独性能更新。
