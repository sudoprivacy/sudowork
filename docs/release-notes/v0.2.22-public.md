## v0.2.22

### 重要修复

- 修复桌面端在部分启动异常后，点击“获取验证码”可能导致应用直接退出的问题，恢复短信登录。
- 修复已安装 Sudocode 的版本识别，避免覆盖用户已有的更新版本。
- 改善 Windows 技能目录加载与重试，以及 WebUI 断线重连、页面重试和定时任务状态刷新。

### 新功能

- 增加私有会话备份与恢复能力，便于保留工作上下文。
- 增加可选浏览器操作后端，改善原生浏览器兼容性。

建议桌面端用户及时更新。
