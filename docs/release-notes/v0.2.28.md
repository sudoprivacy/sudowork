# v0.2.28

Desktop updates preserve a custom installation directory instead of moving the app into a product subdirectory. The installer records program files separately so upgrades, uninstall and reinstall retain user files.

Nexus daemon v0.8.2 and SDK v0.5.1 restore ACP conversations after mailbox retention. Packaged acceptance covers upgrade, cold reinstall and automatic update with the original personal Agent, ACP session and a fresh reply recalling saved memory. Vault v0.5.68 remains pinned.

Release validation checks the desktop and shared renderer workspaces. Candidate promotion binds regression builds and the RC tag to the reviewed Nightly commit, checks both package versions, and requires main and the stable tag to have exactly the reviewed source tree. It preserves separate main history and stops if merging main changes the audited contents. The existing manual audit remains required.
