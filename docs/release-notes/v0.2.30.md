# Sudowork v0.2.30 Release Note

> 自 v0.2.28 起累计 26 个非合并提交：5 个新功能、16 个修复、2 个测试，以及 3 项工程维护与重构。

## 重点新功能

### 组织模型账户与充值中心

- 新增组织共享模型余额、成员额度与个人用量视图，管理员可集中查看组织与个人的用量、余额和交易记录。
- 支持管理员创建、继续及取消支付宝或微信充值订单，并展示入账来源与订单状态，覆盖组织模型余额的完整充值流程。
- 在余额服务或成员用量服务短暂不可用时，保留充值入口与已支付状态，避免用户因临时服务故障误判充值结果。

### 按个人 Agent 身份管理会话

- 会话按稳定的个人 Agent 身份聚合，可在同一 Agent 的会话列表中切换已有会话或新建会话。
- 全局“新建会话”默认进入用户的个人默认 Agent，不再沿用当前会话的 Agent 上下文。
- Agent 身份仍在加载时保留用户已输入的草稿；会话创建失败时也不清空草稿。同名模板不再导致 Agent 身份被错误匹配。

### 已发布 Agent 的本体会话入口

- 本体工作台的发布页面支持直接为已注册 Agent 新建会话。
- 恢复本体会话时会加载已发布版本对应的规则、MCP 查询工具和凭据，并恢复历史工具调用。
- 工具名称在发送至模型 API 前限制在允许长度内，同时保留原始名称备份，提升长工具名场景的会话兼容性。

### 受管云 Agent 工作台共享

- 已通过验证的管理者可访问由自己发起的受管 Agent 会话。
- 工作台明确展示 Agent 与计费归属信息，并继续保持所有者写入锁语义，避免多人操作造成会话状态冲突。

## 重要修复

### 云会话与远程工作区稳定性

- 云会话创建和恢复的最长等待时间提升至 180 秒，避免运行时准备较慢时被元数据超时误判为启动失败。
- 修复远程定时任务时间、手动任务启停、远程产物记录、工作区文件链接及预览等回归问题。
- 运行时只管理自身启动的 Nexus 进程，不再接管或终止占用端口的外部进程，避免影响用户已有的本地服务。

### WebUI 与会话体验

- 保留 WebUI 中工具调用的成功或失败结果及流式空白内容，避免工具卡片展示不完整。
- 登录被 Moss 策略拒绝时，保留并展示原始拒绝原因，便于用户理解访问限制。
- 活动 WebSocket 与终端操作会重新校验管理授权；撤销授权后及时关闭相应连接，确保受管会话访问边界保持一致。
- 云终端仅接入实际可用的 Agent runtime，不再在 WebUI 主机上伪造本地 shell。

### 充值与模型服务可靠性

- 保留充值请求的截止时间和幂等恢复信息，减少网络波动或重试带来的支付状态丢失。
- 用量和余额服务临时异常时，继续显示充值能力和已完成支付状态，避免误导用户重复充值。

## 性能

- 调整桌面端启动顺序：优先注册存储与 IPC，再创建窗口，并在渲染后并行准备运行时服务，降低桥接未就绪导致的首屏重试概率。
- 本次未引入可量化性能基准；上述改动以提升启动可靠性和资源生命周期稳定性为目标。

## 工程重构（无功能变更）

- 桌面端将 Nexus/VFS 安装、服务能力以及密钥和文件会话客户端委托给 Sudocode，移除旧的独立 Nexus-VFS 打包链路。
- CI 从单一 `packageManager` 配置读取 Bun 版本，减少运行时版本来源不一致的风险。
- 更新 `ai-dev-browser` 依赖，并补充受管 Agent 关停和 ACP 工作区路径相关测试。
- 完善 v0.2.28 候选构建的审计与晋级绑定，确保稳定标签关联已审核的候选构建内容。
