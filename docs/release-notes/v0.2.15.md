# Sudowork v0.2.15 Release Note

> 自 v0.2.14 起累计 38 个提交（feat 5 / fix 20 / test 1 / ci 12）。本版本聚焦**客户端本地知识库、运行时安装链路、团队会话稳定性与 scode 自动模型配置**，并补齐分支 Windows 构建流程。

## 重点新功能

### 本地知识库

- 新增客户端本地知识库能力，支持在桌面端管理本地知识库数据与运行时依赖
- 新增本地知识库管理界面，完善知识库列表、状态展示和配置入口
- 支持 embedding model runtime 安装入口，用户可在本地知识库链路中安装向量模型运行时
- 新增 Poppler runtime installer，为本地文档解析链路提供运行时安装能力

### scode

- 支持可配置的 auto model，为自动路由模型选择提供配置入口

## 重要修复

### 本地知识库

- 修复向量运行时打包缺失 `sharp` vendor 的问题，避免发布产物中本地向量能力无法启动
- Poppler 安装路径调整到 nexus data 目录，减少与应用包路径和系统权限的耦合
- Poppler 安装 staging 流程收敛，重写 stage symlink，降低运行时安装失败概率
- Poppler 验证逻辑支持「可运行但无版本输出」的环境，避免误判安装失败
- Poppler 安装失败时补充诊断信息，并在验证失败后增加重试
- 设置 Poppler library path，修复部分平台动态库解析失败
- 格式化数据库冲突解决逻辑，减少本地知识库数据库异常时的处理不一致
- 优化知识库 UI 细节，提升本地知识库管理流程的可读性和操作稳定性
- 移除本地知识库相关提交中混入的无关 builder config 变更

### 团队会话

- 阻止团队会话中调用 Sleep tool，避免成员 turn 进入 busy-wait 状态
- 消除团队成员重复消息气泡，减少协作视图中的重复输出
- 团队会话中跳过 fallback completion message，避免生成额外无意义消息
- 团队面板聚合所有成员产物，修复仅展示部分成员 deliverables 的问题
- 启动清理器不再删除团队 workspace 目录，避免团队数据被误清理

### 认证与模型路由

- 恢复登录态时，在 token refresh 后重新注入凭据，修复恢复流程中凭据未生效的问题
- 更新 scode auto router model，确保自动模型路由使用最新模型配置

## 性能

- 本版本无独立性能类提交。

## 工程重构（无功能变更）

### CI / 构建

- 新增 branch Windows build workflow，并支持手动选择分支构建
- 分支 Windows 构建改为显式 checkout browser package，并在构建前初始化 browser submodule
- 分支构建从 workspace root 执行，减少子目录上下文导致的路径问题
- 修复 manual build push 默认值，并支持 push 触发分支 Windows 构建
- Windows ARM64 unpacked path 与 Linux executable casing 的构建检查更宽容，提升跨平台构建兼容性
- 移除临时 branch Windows workflow 变更，并回退临时 workflow 调整，保留正式流程

### 测试

- 补充 Windows Poppler 环境测试，覆盖本地知识库运行时安装验证路径。
