# Sudowork v0.2.13

### 新功能

- 支持发送消息时中断当前回答：运行中可直接提交新消息，ESC 中断本轮，上箭头取回排队中的消息
- 应用更新支持差分升级，下载更新包更小更快
- 支持企业 CAS 单点登录（SSO），并完善登出流程
- 技能选择器改版：@ 与技能按钮统一为同一弹窗，支持文件列表标签页，关闭后自动聚焦输入框
- 定时任务：管理员/协作者在客户端定时功能关闭时仍可管理已有任务
- 启动时自动清理残留的临时工作区，只有自定义工作区才显示删除选项

### 修复

- 修复远程会话中图片无法作为图像内容被模型识别的问题
- 修复暗色模式主色不一致等一系列主题与样式问题
- 补齐技能、图标等模块的多语言文案，避免个别界面显示中文

### 优化

- 大量界面细节与图标体系统一，视觉更一致、暗色模式表现更好
