# Sudowork v0.2.14 Release Note

> 自 v0.2.13 起累计 8 个提交（feat 2 / fix 4 / chore 1 / docs 1）。本版本聚焦**团队成员管理与会话内工具权限**，并升级 nexus-vfs（serve-local + v0.6.0）与 scode 运行时（0.1.14 → 0.1.15）。

## 重点新功能

### 团队成员管理

- 支持对团队成员进行新增 / 移除 / 重命名，成员管理闭环完整
- 团队详情页拆出 `TeamAddMemberModal` / `TeamAssistantCandidateCard`，成员列表（`TeamMemberListTab`）交互重构

### nexus-vfs

- 采用 serve-local 模式，pin 升至 v0.6.0

## 重要修复

- **团队成员工具权限**：为团队成员启用 yoloMode（`bypassPermissions`），避免无人交互场景下 MCP 工具（如 `team_send_message`）被 claude-agent-acp 权限层阻断
- **team-mcp 打包**：打包阶段补齐 team-mcp，避免发布产物缺失
- **团队成员 UI**：成员状态在 hover 下稳定、操作图标改进、重命名输入框放大、编辑态成员行高稳定

## 运行时升级

- scode：0.1.14 → 0.1.15

## 工程重构（无功能变更）

- 修正 PTY 覆盖率规划文档（§3.2：3/4 live-capable，batched_flush 为 mock-only）
