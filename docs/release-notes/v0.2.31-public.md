## v0.2.31

### Features

- Cloud conversations now have a shared browser panel and a viewer that opens
  in a new tab. Watch and operate the same browser session as your AI.
- Take control for login or a manual step, then return the browser to AI with
  a note about your changes.
- Start, stop or restart the browser while retaining its profile and login
  cookies. Choose visible or headless browsing and an available browser mode.
- Upload files through the page's native file chooser and save completed
  downloads from the browser panel.
- Start installed agents directly from their cards and return to their latest
  conversations.

### Fixes

- Personal cloud agents and managed conversations preserve the owner's model
  and restore authorized conversation history.
- Switching agents or accounts shows the matching history and clears old
  cached drafts. Reloaded idle conversations show accurate status.
- Cloud model selection refreshes after cancellation.
- Browser handoff and artifact history work after conversation reload, and the
  cancel button is easier to identify with assistive tools.

Cloud browser features require a configured cloud browser service.
