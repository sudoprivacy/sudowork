# Sudowork v0.2.17 Release Note

> 自 v0.2.16 起累计 53 个提交（feat 10 / fix 18 / refactor 8 / test 8 / chore 5 / style 3 / docs 1）。本版本聚焦**ACP nexus 隧道、团队会话加固、FFmpeg 运行时打包、TaskPanel 架构重构与智能体 Hub 多租户**。

## 重点新功能

### ACP Nexus 隧道

- 新增 nexus VFS gRPC-JS 客户端，为 ACP 隧道提供 gRPC 通信层
- Agent 启动链路支持通过 nexus 隧道路由（StartSession + fd streams），减少对本地进程 spawn 的依赖
- 隧道 agentId 增加 node-anchor + conversationId-trace，提升调试可追溯性

### FFmpeg 运行时打包

- 新增 FFmpeg 运行时捆绑能力，为技能调用链提供 FFmpeg 可执行文件
- CI 构建流程自动下载 + 打包 FFmpeg（pin BtbN build + sha256 校验）
- `getFfmpegBinDir` 改为 best-effort（不 throw），避免缺失 FFmpeg 时中断其他流程

### 智能体 Hub

- 支持多租户智能体可见性（multi-tenant visibility），企业模式下可按租户隔离智能体列表
- 安装 Hub 智能体时信任包元数据而非过期列表字段，减少安装异常

### IM 频道

- 企业模式下支持为每个 IM 频道选择默认 Agent

### 任务面板（TaskPanel）

- useTaskDags hook 重写，数据源从 `.tasks/dag_*/` 切换为 sudocode TaskRegistry 的 `.sudocode-tasks.json`（SSOT）
- DAG 分组改为从依赖关系图的连通分量自动推导，不再依赖显式 dag_id
- 删除旧的 taskPanelUtils.ts（DAG 文件管理逻辑不再需要）
- Mini tracker UX 改进：Arco Tooltip 替代原生 title、圆点 hit area 扩大到 24px、并行任务加边框、max-height 从 100px 提升到 240px
- TaskPanel 位置从文件树上方移到下方，避免视觉割裂

### 其他新功能

- 支持外部图像模型配置入口
- 新增充值申请模式（credit application mode）

## 重要修复

### 团队会话

- 加固成员故障生命周期：crash disposal、retry-start、中断通知
- 加固取消语义、watchdog 降级、crash 恢复生命周期
- 加固详情页导航、removeMember guards、EventLoop 错误处理
- 删除团队时 workspace-deletion checkbox 生效

- 加固 fallback prose dedup 和 auto-retry empty user turns
- 修复 team_list_models 数据源
- 恢复团队助手合并中 bare preset agents

### 运行时安装

- scode / nexus-vfs 下载链路支持 HTTP(S)_PROXY 代理
- pin scode 0.1.24（支持 oversized tool-output offload）

### Hub 与技能

- 新增上传诊断日志调试个人技能上传失败
- 传播本地化示例提示词到 API、sync、installer 全链路

### 认证与 UI
