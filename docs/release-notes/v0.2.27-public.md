# v0.2.27

- 修复应用启动发现更新后错误提示“当前系统架构没有匹配的安装包”、下载按钮不响应的问题。
- 自动更新使用已验证的平台更新包，加载更新说明失败不会阻止下载；只有确认没有可用安装包时才引导手动下载。
- 登录页也可接收启动更新提醒、使用应用菜单检查更新；应用启动较慢时不再丢失更新通知。
- 包含 0.2.26 的旧登录地址自动迁移、短信登录、充值中心、Opus 工具历史配对和 Logo 修复，以及此前的新 Mac 安装与核心启动修复。

旧版停在登录页时，可从官网覆盖安装；0.2.24 的架构提示属于旧版界面问题，可点击“下载并安装”更新。0.2.25 回滚版需点击“暂时跳过”，再用菜单“Check for Updates...”检查更新，或从官网下载覆盖安装。
