# v0.2.27

The update dialog now treats the native updater feed and the optional manual installer metadata as independent download routes. Startup notifications and explicit checks use the same candidate handling; delayed, failed, mismatched, or stale release details cannot disable a valid native update. Nightly releases retain manual installation.

The desktop update dialog mounts outside authenticated routes and replays the main process update status after subscribing, so login and slow startup do not lose the update entry point. A late snapshot cannot overwrite newer live progress.

Includes all v0.2.26 fixes and the pinned SudoCode v0.2.22 runtime.
