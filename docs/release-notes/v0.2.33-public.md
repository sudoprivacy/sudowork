## v0.2.33

### Features

- Use a shared browser panel or open its viewer in another tab. You and AI
  work in the same browser session on Desktop and WebUI.
- Take control for login, file selection or another manual step. Return to AI
  with a note; it observes your changes before continuing.
- Keep compact Desktop controls above Chrome while the main panel is hidden.
- Start, stop or restart the browser while retaining its profile and cookies.
  Visible and headless browsing use the same session controls.
- Upload files through the website's chooser and save verified downloads from
  the browser panel.
- Install WebUI offline on AMD64 or ARM64 hosts.

### Fixes

- Human typing and clicks finish before AI resumes after handoff.
- Browser views stay usable as download and tab history grows, including in
  Firefox. Pending permissions survive conversation reload.
- Desktop installers include and validate both browser connection adapters.
- Agent switching, owned conversation history and selected cloud models remain
  consistent across reloads.

Cloud browsing requires a configured managed browser backend. Connecting an
existing personal Chrome profile and physical iPhone/Safari support remain
under separate validation.
