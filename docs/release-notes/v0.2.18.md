# Sudowork v0.2.18 Release Note

> 本次为 Sudo Code 运行时专项维护版本。

## 重要修复

- 内置 Sudo Code 从 `0.1.24` 升级到 `0.2.11`。
- Claude 模型恢复使用 `/v1/messages`，避免静默降级到缺少 `cache_control` 的 `/v1/chat/completions`，恢复 prompt cache 并降低重复 token 成本。
- 包含 `metadata.user_id` 渠道亲和性修复。

## 验证

- 校验 macOS arm64 官方发布资产 SHA-256。
- 使用真实 `scode 0.2.11` 二进制验证 ACP `initialize`、`session/new` 与 `session/cancel`。
- 相关单测、完整测试与 TypeScript 检查通过。
