# Sudowork v0.2.19 Release Note

> 自 v0.2.18 起累计 3 个提交（fix 2 / docs 1）。本版本聚焦 **ACP Nexus 长轮询稳定性**与 **WebUI 上游连接故障诊断**。

## 重要修复

### ACP Nexus 隧道

- 修复 Nexus SDK `0.3.0` 将 `connectTimeoutMs` 应用于所有 RPC 后，阻塞式读取可能在守护进程长轮询返回前超时、导致空闲隧道断开的问题。
- ACP 传输层根据长轮询时长计算 RPC 超时，至少保留 15 秒余量并设置 30 秒下限。
- Nexus VFS gRPC 客户端支持注入 RPC 超时配置，避免连接建立与长轮询读取共用不合适的默认值。

### WebUI 上游连接

- 未识别的上游连接异常现在会在 WebUI 服务端记录原因，同时继续向浏览器返回不包含 MOSS 内部信息的 `UPSTREAM_FAILED`，兼顾可诊断性与信息隔离。
- 故障日志仅记录截断后的 principal 与 session 标识，便于关联问题且避免输出完整标识。
- 补充部署配置说明：`MOSS_BASE_URL` 的 host 必须与 MOSS `publicBaseUrl` 保持一致，否则 MOSS 返回的 WebSocket 地址会在建连前被客户端拒绝。

## 测试

- 增加 ACP 长轮询读取回归测试，覆盖 RPC 超时配置及空闲响应场景。
- 增加 WebUI 会话流集成测试，验证未知上游错误会写入服务端日志且不会泄露到浏览器错误消息。
