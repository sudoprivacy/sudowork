# Sudowork v0.2.20 Release Note

> 自 v0.2.19 起累计 1 个提交（fix 1）。本版本聚焦 **个人用户中心与充值中心的数据加载稳定性**。

## 重要修复

### 用户中心与充值中心

- 修复桌面端主进程的认证服务器地址解析错误地依赖 renderer 配置桥接，导致 IPC provider 一直等待、用户中心和充值中心在发起网络请求前持续加载的问题。
- 主进程改为从 ProcessConfig 同步读取当前模式和服务器地址，保留企业服务器优先、个人服务器覆盖与默认地址回退的解析语义。
- 恢复用户中心的今日使用、模型用量以及充值中心的积分、套餐与订单记录请求。

## 验证

- 通过 Electron CDP 验证 `sudowork-server.get-config` IPC 能即时返回认证服务器地址。
- 验证用户中心发起 dashboard 与 model-usage-stats 请求，充值中心发起 dashboard、套餐和订单列表请求并成功渲染。
