# Sudowork v0.2.13 Release Note

> 自 v0.2.12 起累计 258 个提交（refactor 112 / style 52 / fix 37 / feat 18 / docs 17 / test 12 / chore 9 / ci 1）。本版本聚焦**会话中断与消息队列、差分更新、企业 SSO 登录**，并完成大规模前端重构（图标体系迁移、AionModal 下线、agents/skills 模块化、UnoCSS 规范化）。

## 重点新功能

### 会话中断与消息队列（interrupt × queue）

- 新增 `turnInputCoordinator` 作为「中断 × 队列」矩阵的 SSOT
- 桌面输入框支持运行中提交（submit-while-running）、ESC 中断当前轮、上箭头取回队列中的消息
- 渠道消息统一经共享 coordinator 路由，与桌面输入走同一套中断/排队语义
- 队列 flush 采用批量语义（batched-flush，非顺序逐条回放），并补充回归守护

### 应用更新

- 支持差分更新（differential app updates），减小增量升级体积

### 登录与企业 SSO

- 支持第三方 CAS 认证登录，用于企业 SSO 场景
- 支持 CAS 登出与服务端回调模式（server callback mode）

### Cron 调度

- 客户端 cron 关闭时，owner / co-owner 仍可管理已有定时任务
- 门控 scode 自带的 agent cron 工具 —— 调度权由 sudowork 统一持有

### 技能选择器（skill-selector）重构

- 用 `SkillSelectorPopover` 替换 `SkillSelectorMenu` 与 @ 按钮的输入触发方式，合并两条渲染路径
- 支持非受控标签页模式，Sendbox 接入文件列表标签页
- 关闭后自动聚焦输入框（`onAfterClose`）；键盘导航与搜索逻辑下沉到弹出组件

### Workspace 清理与生命周期

- 新增 `conversationReaper` SSOT 模块，统一 `conversation.remove`、预设助手删除等路径走 reaper 回收，并为泄漏的 conversation 缓存补充 disposer
- 启动时清扫孤立的临时 workspace 目录
- 仅自定义 workspace 显示「删除工作区」勾选框

### 渲染与渠道

- 远程会话的行内图片作为 vision blocks 注入模型轮次
- 智能体模块新增安装/复制/上传/企业发布等能力，SkillCard 支持整卡点击切换选中

## 重要修复

- **企业 SSO**：修正第三方 CAS 登录/登出链路
- **nexus-vfs**：移除 `--bootstrap-mode`，CI 集群改用 `--insecure-no-auth`；运行时 0.4.0 → 0.5.0
- **scode**：识别 linux 平台、修正 seeder marker 名称，门控其 cron 工具
- **CI**：为 better-sqlite3 重建 Electron ABI、修正 chrome-sandbox 权限、重排 e2e 启动与 Xvfb 链路
- 技能/图标等模块补齐多语言，修复不同语言下显示硬编码中文
- 暗色主题主色与 Arco 同步、`scrollbar-hide` 工具类兼容性等样式修复

## 工程重构（无功能变更）

- **图标体系迁移**：settings、layouts、agents、skills、guid、cron、security 等模块由 `@icon-park/react` 迁移至 `lucide-react` / Arco Icon，fill 统一为语义色/currentColor
- **AionModal 全面下线**：enterprise-mcps、custom-acp-agent、bdpan 等弹窗改用 Arco Modal，删除 AionModal 组件与专属 CSS
- **模块化拆分**：agents / skills 从设置页拆分为独立顶级页面，types/utils 归集为 barrel 目录，内联组件抽离
- **UnoCSS 规范化**：像素间距统一替换为 scale 单位，硬编码颜色替换为语义色板 token（含暗色模式修复）
- Message 实例调用统一为静态 API；EmptyState、EmojiPicker、FilePreview 等组件迁移与内聚
- 移除渲染层文件头 license 注释；新增 DGX Spark 本地栈架构设计文档
