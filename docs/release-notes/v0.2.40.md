# Sudowork 0.2.40

Desktop now installs scode 0.2.37, enabling the shared input queue delivered in
Sudowork #1312 and scode #1081. Desktop and WebUI send input intents to the agent
engine and display its authoritative queue state.

- Enter steers an active agent at its next safe boundary.
- Tab queues a draft for a later turn while the agent is working.
- Escape flushes pending input, or cancels when there is nothing to flush.
- Ctrl+C cancels; selected text in the browser keeps its normal copy behavior.
- Background task completion can wake an idle agent without another user message.
- Recalling a queued human draft preserves attachments, skills and selected page
  fragments.

Cloud conversations require a Moss release with scode and nexusd-cohost 0.2.37.
Update the server runtime as well as the WebUI application. Agents that do not
advertise input-delivery v1 retain their existing controls. Pending drafts are
held in memory and are not a crash-recovery store.
