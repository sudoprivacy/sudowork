## v0.2.30

### 新功能

- **组织模型账户与充值中心**：可查看组织余额、成员额度和用量记录；管理员可通过支付宝或微信为组织余额充值并跟踪订单状态。
- **更清晰的 Agent 会话管理**：会话按个人 Agent 聚合，可在同一 Agent 下快速切换或新建会话；全局新建会话会自动进入默认 Agent。
- **已发布 Agent 可直接开始对话**：可从已发布 Agent 的工作台创建会话，并恢复其配置与工具上下文。
- **受管云 Agent 工作台共享**：管理者可访问自己发起的受管 Agent 会话，更方便地协作和查看归属信息。

### 修复与优化

- 改善云会话创建和恢复的稳定性，运行时准备较慢时不再过早判定为启动失败。
- 修复远程定时任务、手动任务控制、工作区文件链接与预览等问题。
- 输入草稿在 Agent 加载或会话创建失败时会保留，减少意外丢失。
- 改善充值状态、用量与余额服务短暂异常时的显示，避免重复充值或误判支付结果。
- 补全 WebUI 中工具调用的流式结果展示，并优化登录限制提示。
- 加强云会话权限与终端访问边界，提升受管工作区的安全性和稳定性。
- 优化桌面端启动可靠性，减少首次打开时的连接重试。
