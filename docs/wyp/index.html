1这是什么

Sudowork（仓库 sudoclaw/sudowork，北京数牍科技）是一个基于 Electron 的桌面 AI Agent 平台，定位为"企业 AI 应用平台 / AgentOPS / 办公专家"。

核心价值：把各种 CLI AI Agent（Claude Code、Codex、Qwen 等遵循 ACP 协议的工具）包装成统一的图形界面，并支持远程访问（浏览器 WebUI）和即时通讯软件接入（Telegram / 飞书 / 钉钉 / 微信等），还能跑定时任务。

⚠️ 文档新鲜度提醒：仓库里的 project.md 部分内容已过时（写的是版本 1.8.26、src/worker/ 目录，实际 package.json 是 0.2.7，worker 已并入 src/process/task/）。本文基于实际源码绘制。

三个进程的关键纪律：Renderer 无 Node API，Main 无 DOM API，跨进程通信必须走 IPC Bridge（src/preload.ts + src/common/ipcBridge.ts）。

进程目录职责
Main 主进程src/process/应用逻辑、SQLite、服务编排、spawn Agent 子进程
Renderer 渲染进程src/renderer/React UI、聊天界面
Agent 子进程由 Main spawn实际运行的 ACP CLI 工具（Claude Code 等）

两个外部访问入口（都在 Main 进程内）：

  • WebUI（src/webserver/）：Express + WebSocket，把同一套打包好的 React 应用通过浏览器提供出去，支持远程访问。
  • Channels（src/channels/）：Telegram / 飞书 / 钉钉 / 企业微信 / 微信 / 禅道 机器人，让你在 IM 里直接和 Agent 对话。

4各层模块速查

Main 进程 src/process/

模块作用
index.ts初始化编排：initStorage → initBridge → ExtensionRegistry → 按 appMode 启动服务
bridge/50+ 个 IPC 桥，Renderer 调用 Main 的入口（conversation / auth / model / mcp / cron ...）
database/SQLite（better-sqlite3）：conversations / messages / users / 自定义模型 provider
task/Agent 执行核心：BaseAgent、AcpAgent、RemoteAgent、技能管理、消息中间件
services/后台服务：cron 定时、mcp、nexus-vfs（虚拟文件系统）、scode、providers、telemetry
WorkerManage.ts内存任务注册表：conversationId → Agent 实例，负责创建 / 缓存 / 退出清理

Renderer src/renderer/

  • 路由：React Router v6 HashRouter。主要页面：/guid（首页/会话列表）、/conversation/:id（聊天）、/settings/*、/moss-session/:id（企业）。
  • 状态管理：纯 React Context（无 Redux/Zustand）+ SWR 做服务端数据缓存。
  • 聊天 UI（messages/）：Virtuoso 虚拟列表，支持多种消息类型——文本、工具调用（MessageToolCall）、计划（MessagePlan）、Agent 状态、ACP 权限审批弹窗（acp/MessageAcpPermission）。
  • 三栏布局（pages/conversation/ChatLayout）：左=消息流，中=工作区（文件树/技能/任务），右=预览面板（浏览器/代码 diff）。

Channels src/channels/（IM 机器人接入）

子目录作用
core/ChannelManager 单例 + PluginManager + SessionManager
plugins/telegram / lark / dingtalk / wechat / wecom / zentao 各平台实现
pairing/配对授权：IM 用户发 /start 拿 6 位码 → 在设置里审批绑定
agent/消息流式回传、事件总线（ChannelEventBus）、响应路由

WebServer src/webserver/（浏览器 WebUI）

  • Express + ws，服务同一套打包好的 React 应用（out/renderer/）。
  • 认证：bcrypt 密码 + JWT，Cookie 名 sudowork-session，支持二维码登录。
  • 默认端口 25808，--remote 开放局域网访问，--resetpass 重置管理员密码。
