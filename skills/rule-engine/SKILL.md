# 规则引擎 Skill

## 能力

- 加载并执行品类映射规则（返厂管理场景）
- 超时分级规则（7/14/30 天三级）
- 物流异常检测规则（3 天无更新 = 停滞）
- 唯一码生成规则（订单号 & SKU）
- 汇率转换（VLOOKUP 汇率表）
- 科目映射（VLOOKUP 映射表）

## 使用方式

当需要对数据应用业务规则时调用本 Skill。规则以声明式配置驱动，支持条件匹配、映射查找、分级标记等操作。

### 品类映射

根据商品品类判定是否允许返厂：
- 普通品类 → 自动判定
- 特殊品类（小型机械/气动工具/测量工具）→ 转人工审批

### 超时分级

| 天数 | 等级 | 标记 |
|------|------|------|
| ≤7 天 | 正常 | 无 |
| 7-14 天 | 紧急 | 黄色 |
| 14-30 天 | 超时 | 橙色 |
| >30 天 | 严重超时 | 红色 |

### 汇率与科目映射

- 汇率表：11 行，多币种转换
- 科目映射表：154 行，财务科目标准化
- 计算公式：`ROUND(金额 * 汇率, 2)`
