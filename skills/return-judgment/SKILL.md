# 返厂判定 Skill

## 能力

对每条返厂单据进行可行性判定，输出判定结果和依据。

## 判定逻辑

### 自动判定（普通品类）

1. 检查品类是否在可返厂列表中
2. 检查是否超过返厂时效
3. 检查物流状态是否正常
4. 综合判定：通过 / 拒绝

### 转人工审批（特殊品类）

以下品类必须转人工审批，不得自动放行：
- 小型机械
- 气动工具
- 测量工具

## 输出格式

每条单据输出：
- `judgment`: `approved` | `rejected` | `need_human_approval`
- `reason`: 判定依据说明
- `urgency`: 超时等级（正常/紧急/超时/严重超时）
- `logistics_status`: 物流状态（正常/停滞/异常）

## 决策红线

**宁可漏报，不可误报** — 存疑时标记为需人工审批。
