# 抽查检查

**分类:** 工商信息
**路径:** `POST /v1/company/industrial/checkups`
**Content-Type:** `application/json`

### 字符编码
UTF-8

### 请求地址
/v1/company/industrial/checkups

### 请求方式
POST(application/json)

### 请求参数

| 参数名 | 类型 | 长度 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| cid | Integer | - | 否 | 企业id |
| companyName | String | 255 | 否 | 企业名称 |
| creditCode | String | 255 | 否 | 企业统一社会信用代码 |
| pageIndex | Integer | - | 否 | 页数 |
| pageSize | Integer | - | 否 | 条数 |


#### 请求示例

```
{
  	"companyName": "河北史蒂斯机电设备安装工程有限公司",
	"pageIndx":1,
	"pageSize":1
}

```

### 响应参数

| 参数名 | 类型 | 长度 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| companyId | Integer | - | 是 | 企业id |
| date | String | 50 | 否 | 检查日期 |
| department | String | 100 | 否 | 检查实施机关 |
| result | String | 2000 | 是 | 结果 |
| type | String | 50 | 否 | 类型 |
| totalCount | Integer | - | 是 | 总条数 |
